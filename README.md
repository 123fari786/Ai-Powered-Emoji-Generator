# 🤖 AI-Powered Emoji Generator

A modern **Flutter-based AI Emoji Generator** that allows users to create unique and expressive emojis using AI-powered generation features. The application provides multiple ways to discover, create, customize, preview, and manage personalized emojis and stickers through a clean and user-friendly mobile interface.

## ✨ Features

* 🤖 **AI-Powered Emoji Generation** — Generate custom emojis from text prompts.
* 🖼️ **Image to Emoji** — Transform images into personalized emoji-style creations.
* 🎨 **Custom Emoji Creation** — Create unique emoji designs based on user input.
* 😍 **Sticker Generation** — Generate and manage creative stickers.
* 🔍 **Discover** — Explore generated and available emoji content.
* 🗂️ **My Emojis** — View and manage previously generated emojis.
* 👀 **Preview Screen** — Preview generated content before using or saving it.
* ⭐ **Rating System** — Allow users to rate generated content.
* 💎 **Premium Features** — Premium functionality and subscription-related UI.
* ⚙️ **Settings** — Manage application preferences and user options.
* 🌈 **Modern UI** — Clean, responsive, and mobile-friendly interface.
* 🔥 **Firebase Integration** — Firebase services used for application functionality and backend integration.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/123fari786/Ai-Powered-Emoji-Generator.git
```

### 2. Navigate to the Project

```bash
cd Ai-Powered-Emoji-Generator
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Configure Firebase

Make sure your Firebase configuration is properly set up for your development environment.

### 5. Run the Application

```bash
flutter run
```
